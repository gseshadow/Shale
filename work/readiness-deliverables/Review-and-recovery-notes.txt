  bootstrap or any existing identity. No existing identity is converted by this packet.

  Later bootstrap table DENYs are retained, including phase3b2b/phase3b2c1/phase3b3.

  and 42 legacy/private EXECUTE DENYs = 228 exact permission edges.
- Verifier: database VIEW DEFINITION; SELECT on sys.sql_expression_dependencies;
  SELECT on AiCaseDataDeployment, AiDataUnicodeRange, AiDataUnicodeLower,
  AiDataWordTransition = 6 edges. No application EXECUTE.

- Hash-pinned role-contract.json records source expectations, not a live-derived baseline.

Stop and recovery
- Any finding, incomplete metadata, NULL required evidence, absent/invalid secret,
  unexpected existing identity, wrong credentials, changed catalog or nonzero exit:
  STOP and keep ALL controls OFF. Never grant broad rights to make a check pass.
- Before commit: the script attempts rollback of its uncommitted transaction only.
  Verify rollback read-only; it never drops pre-existing users or revokes any grants.
- COMMIT timeout/disconnect: outcome UNKNOWN even if the client did not receive success.
  Do not retry automatically. Reconnect in Preflight, reconcile all three users, exact
  memberships and SIDs; use Verify only after determining committed state. A later
  separately authorized rerun is idempotent only for existing exact, working identities.
- Post-commit verification failure: committed users remain; preserve evidence, stop and
  diagnose read-only. Remediation/rotation/revoke/drop needs its own reviewed authorization.
- Rollback cannot be confirmed: close the process, have DBA determine transaction and
  lock state, then reconcile read-only. No automatic destructive cleanup or SQL repair.
- Do not export raw exception records, $Error, command/connection/credential objects,
  server batch text or traces during diagnosis. Retain bounded stage/error status only.
